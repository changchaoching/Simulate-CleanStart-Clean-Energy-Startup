遊戲核心決策與模擬機制

在模擬中，玩家扮演一家致力於提升商辦大樓能源效率的清潔科技 (CleanTech) 新創公司創辦人兼執行長，在 24 季（6 年）的營運週期中面對以下核心抉擇：





產品定價策略 (Product Pricing)：平衡價格吸引力與毛利率。



團隊人才擴張 (Engineers vs. Salespeople)：





研發工程師 (Engineers)：推動產品節能效率與技術突破，並提供安裝交付能力。



業務銷售人員 (Salespeople)：拓展商辦大樓市場知名度、爭取新訂單。



激勵性薪酬結構 (Compensation Package)：





季薪底薪 (Salary)



股票選擇權 (Stock Options)



利潤分享分紅 (Profit Sharing)



調節員工士氣、離職率與研發/銷售生產力。



融資策略抉擇 (VC Funding vs. Bootstrap)：





自力更生 (Bootstrap)：不拿創投資金，自負盈虧，保持 100% 員工與創辦人股權控制。



創投加速 (VC Financing)：引進 Seed、Series A、Series B 資金，快速擴充研發與銷售規模以衝刺 IPO，但須承擔每輪 18~22% 的股權稀釋。



製造學習曲線 (Learning Curve)：





隨著累計商辦安裝套數增加，規模經濟與模組標準化將使單位製造成本顯著下降。
